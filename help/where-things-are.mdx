In RN Video on iPhone or iPad, most things start at the top of the Library. On the Mac, they're at the top of the window.
In Lineups, Home lists your teams, and each team has its own tabs.

## RN Video on iPhone and iPad

| To do this | Look here |
|---|---|
| Start a game | **Game**, at the top of the Library |
| Stream a game | **Stream**, at the top of the Library |
| Record short clips | **Moments**, at the top of the Library |
| Bring in videos | **Import videos**, under the cards in the Library |
| Record a coach's lesson | **Skills**, at the top of the Library. It needs a coach code. |
| Carry on a game | **Continue**, under the game in the Library |
| Mark a moment | **MARK**, a volume button, Camera Control, an AirPods stem, or the gimbal's button |
| Fix the score | Tap the score while you record. |
| Tag a moment | Tap the game, then a moment in the list. |
| Make a reel | **Reel ›**, at the top of the game |
| Send a game to the Mac | **Details**, then **Send to Mac** |
| Get help with a gimbal | **Gimbal setup**, on the Ready screen |
| See how it learned hockey | **Acknowledgements**, at the end of the Library |

## RN Video on the Mac

| To do this | Look here |
|---|---|
| Bring a game in | Drag it onto the window, or click **Add a game…**. |
| Bring in other video | **Import…**, at the top or the foot of the sidebar |
| Add more moments | **Add videos…**, in a Moments session |
| Tag moments | **Game**, at the top |
| Pick moments and settings | **Reel**, at the top |
| Make the video | **Export**, at the top |
| Look closer | The <kbd>L</kbd> key |
| Talk to it | Hold the <kbd>T</kbd> key. |
| Take back a change | <kbd>⌘Z</kbd> |
| See how it learned hockey | **Acknowledgements**, in the **RN Video** menu |

## Lineups

| To do this | Look here |
|---|---|
| See what each team needs next | The pill on each team on Home |
| Add a team | **+ Add a team**, on Home |
| Switch teams | The team name at the top of a team |
| Add a game | **New game**, in the **Games** tab |
| Change the next game's lines | **Edit lines**, in the **Games** tab |
| See how each line did | **Line totals**, in the **Games** tab |
| Mark who is out tonight | **Out tonight**, in the **Roster** tab |
| Add more players | **+ Add players**, in the **Roster** tab |
| Read every note | The **Notes** tab |
| Change your name, look or Siri phrases | The gear on Home |
| Delete a team | **Team options**, then **Delete team** |
